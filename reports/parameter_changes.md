# SIM-V0.2-vfov130 参数来源与变更

原包25个文件经 SHA-256 核对后复用，见 baseline_manifest.json。原 ZIP、客户 PDF、组成图、图纸和 USD 均不改写。

本轮唯一用户光学变更为 C0/C1/C2 的 VFOV 显式设为130°。活动配置继承原 layout_parameters.json，保留布局、geometry、采样默认值、客户来源、组成图观察与原有假设。

C0：原工作逻辑以 HFOV 求一个 focal 并令 fx=fy，得到约88.51°垂直视场。工作副本 src/rig_common.py 现独立计算 `fx=W/(2*tan(HFOV/2))`、`fy=H/(2*tan(VFOV/2))`，得到554.256258/251.806135 px，中心主点不变。这是有效仿真内参，不确认存在对应实物镜头。

C1/C2：保持等距投影和半径800 px圆与画幅的交集；原参数本身就对应中央垂直视场130°。新增显式 VFOV 一致性校验，不能用不同数值覆盖等距模型。

C3–C6：保留220°圆形成像解释、直径960 px有效圆、最大离轴110°，没有改成矩形220°。固定结构、朝向、分辨率、HFOV、IMU默认200 Hz及近裁剪0.0001 m均保持。

来源分层：

- 客户 PDF（实际读取10页，重点视觉核对第2/4/6/7页）：前三目水平63 mm/中点关系、HFOV120°/160°、各路最低分辨率、IMU至少200 Hz；PDF没有前向 VFOV130°的原始要求。
- 组成图（实际查看）：四目220°、IMUx1000、右副1630×1300是图上信息，不替换当前配置。
- 基线仿真假设：环视110/40/-16 mm布局、IMU位置、壳体与佩戴占位、光轴和滚转、针孔/等距投影与有效圆。
- 本轮用户确认：前向三目VFOV130°。世界高度1.6 m独立于设备内部外参。

像素约定：连续画幅边界为[0,W]×[0,H]；数组[row,col]的中心为(col+0.5,row+0.5)，主点(W/2,H/2)。边界本身可用于数学FOV定义，但并非额外像素。

派生关系：config/rig_sim_v0.2.json → camera_specs → derived_calibration.json / rig_v0.2.usda / 射线、有效掩膜与输出元数据；每个派生产物记录活动配置SHA-256。
