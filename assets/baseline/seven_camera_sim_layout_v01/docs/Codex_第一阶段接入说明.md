# 第一阶段：只把布局、鱼眼和遮挡跑通

本轮输入是本目录SIM-V0.1仿真布局，客户约束以`sources/customer_requirements_V0.2.pdf`为准。先读取README、参数JSON与名义外参；不得把A项仿真假设修改成客户要求，也不得修改PDF技术指标。确认现场Isaac版本、GPU和环境，不根据经验直接迁移API。

先执行以下工作，不在同一轮引入完整SLAM栈：

1. 在独立目录加载`models/inspection_scene.usda`；不修改现有机器人工程，不运行其他任务。验证7个相机、IMU安装坐标、63 mm基线和七路朝向。CAD用mm、USD用m，注意相机optical坐标与USD坐标差异。
2. 确认实际RTX后端。先做C3/C4角度靶点渲染，人工及像素坐标检查95°和105°射线。LUT或其他schema不能覆盖已经选定的鱼眼属性。若后端不支持，报告失败并用经验证的原生鱼眼或同光心六面采样重投影实现，禁止静默使用针孔。
3. 生成ideal/body/worn三组七路RGB图像，并输出每路有效区域与遮挡分布。有效像圈之外、设备结构、附件、头带、头部应区分；不要把圆外黑边算作结构遮挡。近裁剪面不能把毫米级近邻遮挡件裁掉。
4. 加入0.3/0.5/1/2 m分层测试点或有纹理的球/房间表面，按每路相机真实位置投射射线。输出七目联合覆盖、至少双目覆盖、前向双目共同视场及主要盲区。球面统计要使用立体角权重；图像像素比例与球面覆盖率分别报告。
5. 第一批图像一出来，立即形成预览和关键问题表供用户确认。只汇报真正运行得到的结果；没有运行到的项目写NOT_EVALUATED。不得把仿真真值地图或深度图称为SLAM算法生成结果。

交付：实际环境版本记录、模型加载验证、角度靶点图和像素残差、三种遮挡层各七路预览、覆盖/遮挡统计定义、问题清单。不要先做复杂优化或长稳实验。结构布局确认后，第二阶段再接入连续运动、实际IMU时序和明确支持相机模型的SLAM/VIO算法。
